## Objective

Deliver adjustable application tile sizing, responsive layout configuration, easier naming and movement, a live grid editor, and custom pages for LaunchDeck.

Repository: [https://github.com/Tien-Lam/LaunchDeck](https://github.com/Tien-Lam/LaunchDeck)

## Product outcomes

- Versioned, backwards-compatible configuration with safe migration.
- Deterministic responsive grid shared by the editor and Game Bar widget.
- Adjustable tile spans and layout controls.
- Direct manipulation, inline naming, undo/redo, and cross-page movement.
- Named custom pages with accessible widget navigation.
- Automated verification and review gates before manual Windows/Game Bar acceptance.

## Delivery policy

Linear is the source of truth for all implementation, review, testing, documentation, and release work.

- Every change is attached to an issue.
- Parent gate issues define milestone exit criteria.
- Sub-issues contain independently deliverable work.
- Blocking relations encode execution order across projects.
- Automated and agentic work is scheduled before interactive work.
- Issues labeled **Manual validation** appear only in the final milestone of a project.
- Review feedback that expands scope becomes a linked sub-issue rather than an untracked checklist.
- An issue reaches Done only when its acceptance criteria and required evidence are recorded.
